## 2024-11-06 - [MCP Tool Execution Data Leakage]
**Vulnerability:** The MCP server (`src/router.js`) previously returned the raw error message (`err.message`) from a tool execution failure directly in the JSON-RPC response to the client. Additionally, `dispatchRequest` assumed the input payload was a JSON object.
**Learning:** Returning unhandled tool errors in a public-facing JSON-RPC API over STDIO could expose sensitive internal details such as stack traces, configuration paths, file structures, or environment variables that the tool execution process had access to. A destructuring `TypeError` exception was also possible if the input payload was `null` or a non-object.
**Prevention:** Implement strict payload validation (verify object structure and reject `null`/arrays). Ensure that internal errors occurring during tool execution are caught, logged securely to STDERR (`console.error`), and replaced with generic, non-descriptive error messages (`An internal error occurred during tool execution`) in the response sent to the client.
