# Security Profile

## Security Priorities

1. secure-by-default installation
2. minimal privilege and attack surface
3. supply-chain integrity for updates and images
4. predictable patch and rollback process

## Baseline Controls

- signed boot path and verified updates
- hardened kernel and memory protection defaults
- mandatory app isolation model
- strict network service defaults (deny by default)
- auditable security logging configuration

## Vulnerability Response

- classify findings by severity and exploitability
- patch critical issues before next public release
- publish mitigations and affected component scope
